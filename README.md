# Лепко — прототип

Витрина и конструктор наклеек-подписей: банки, тетради, ящики, инструменты. Заказ от одного листа A6.

Прототип статический: HTML, CSS и JavaScript без сборки и без сервера. Заказ никуда не отправляется.

## Что есть

- **Главная:** посыл «Порядок начинается с подписи», блок про маленькие заказы, галерея готовых решений, категории, как это работает, вопросы.
- **Категории:** 8 тем (кухня, зимнина, школа, детская, мастерская, электрика, дом и переезд, апартаменты), в каждой готовые наборы с фото.
- **Цепочка выбора:** стиль, где будет наклейка (материал), размер листа. На каждом шаге видно, как набор ляжет на лист, и цену.
- **Конструктор:** живое превью листа с метками плоттера и линией реза, текст, вторая строка, форма, размер, картинка, цвета, шрифт, добавление списком с автоподбором картинки, «заполнить лист копиями», цена.
- **Оформление:** форма-заглушка.

## Файлы

```
index.html
css/style.css
js/icons.js   пиктограммы
js/data.js    категории, наборы, стили, материалы, цены листов
js/sheet.js   раскладка на листе, отрисовка наклеек в SVG (единицы — мм), цена
js/app.js     страницы, шаги, конструктор
```

Цены, материалы и наборы меняются в `js/data.js`.

## Запуск локально

```
python3 -m http.server 8000
```

и открыть http://localhost:8000

## Публикация на Cloudflare

Сайт публикуется как Worker со статическими файлами (настройки в `wrangler.jsonc`, исключения в `.assetsignore`).

Cloudflare → Workers & Pages → Create application → Import a repository → `Lepko`. Project name: `lepko`, Build command: пусто, Deploy command: `npx wrangler deploy`. Каждый push в `main` обновляет сайт.

## Фото

Временные фото с Unsplash, авторы указаны в подвале сайта. Заменить на свои фото готовых работ: поле `photo` в `js/data.js`.
